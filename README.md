# Multi-User AI Agent & Schedule Manager (Telegram + n8n)

Интеллектуальный многопользовательский Telegram-ассистент для управления учебным расписанием, повседневными задачами и долгосрочными целями. Построен на базе **n8n**, **PostgreSQL 16**, **FastAPI + OpenAI Whisper** и двухступенчатого LLM-пайплайна.

---

## Ключевые возможности

* **Голосовой и текстовый ввод:** Автоматическая транскрибация голосовых сообщений через локальный микросервис на базе OpenAI Whisper.
* **Двухступенчатый ИИ-роутинг:**
  * *Модель 1 (Препроцессор):* Очищает шум распознавания речи, учитывает историю диалога (последние 5 реплик) и разрешает контекстные отсылки («перенеси её», «отмени это»).
  * *Модель 2 (Исполнитель):* Генерирует компактные JSON-экшены для работы с базой данных без галлюцинаций и лишнего расхода токенов.
* **Гибкая система расписаний:**
  * Разделение на разовые события (`schedule`) и циклическую недельную сетку (`regular_schedule`).
  * Точечная отмена или замена регулярного события на один конкретный день без разрушения основного шаблона (`replace_regular_for_day`).
  * Безопасные точечные патчи через `JSONB` в PostgreSQL.
* **Интерактивный вечерний визард (`[Sub] Evening Wizard`):** Изолированный субагент, который в 21:00 пошагово опрашивает пользователя по невыполненным задачам дня с помощью одной обновляемой карточки (`editMessageText`) и позволяет перенести задачу текстом или голосом.
* **Долгосрочное целеполагание:** Управление целями на год (`YYYY`), месяц (`YYYY-MM`) и ISO-неделю (`YYYY-Wnn`).

## Архитектура и стек

* **Оркестрация:** `n8n` (Docker)
* **База данных:** `PostgreSQL 16 Alpine` (Docker, персистентность через Bind Mounts)
* **Речевой бэкенд:** `Python 3.11+` / `FastAPI` / `OpenAI Whisper` (управление зависимостями через `uv`)
* **Туннелирование:** `ngrok` (статический домен для Telegram Webhooks)

### Структура репозитория
```text
├── docker-compose.yaml      # Стек контейнеров PostgreSQL и n8n
├── .env.example             # Шаблон переменных окружения
├── init_db.py               # Скрипт автоматической инициализации таблиц и индексов
├── pyproject.toml           # Зависимости Python-окружения (uv)
├── whisper-backend/         # Локальный сервер транскрибации речи
└── workflows/               # Экспортированные JSON-схемы воркфлоу n8n
    ├── core_agent.json      # Главный воркфлоу и роутер ИИ
    └── evening_wizard.json  # Субагент вечернего чек-ина
```

## Быстрый старт (Развертывание с нуля)

### 1. Клонирование и настройка окружения
Склонируйте репозиторий и создайте рабочий файл `.env` на основе шаблона:
```bash
git clone https://github.com
cd YOUR_REPO_NAME
cp .env.example .env
```
Откройте `.env` и заполните свои значения (`POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `WEBHOOK_URL`, `N8N_HOST`, `TELEGRAM_BOT_TOKEN`).

### 2. Запуск инфраструктуры в Docker
Поднимите контейнеры базы данных и n8n в фоновом режиме:
```bash
docker-compose up -d
```

### 3. Инициализация базы данных
Установите зависимости через `uv` (или `pip`) и запустите скрипт создания таблиц:
```bash
uv sync
uv run init_db.py
```
*После выполнения в базе будут созданы 5 таблиц (`user_session`, `goals`, `schedule`, `regular_schedule`, `ai_chat_history`) и необходимые индексы.*

### 4. Запуск речевого сервера (Whisper)
Запустите локальный FastAPI-сервер для обработки голосовых сообщений (должен слушать порт, указанный в настройках HTTP-ноды n8n через `http://docker.internal`):
```bash
uv run uvicorn whisper-backend.main:app --host 0.0.0.0 --port 8000
```

### 5. Настройка воркфлоу в n8n
1. Откройте интерфейс n8n по адресу `http://localhost:5678` и завершите первичную регистрацию.
2. Перейдите в раздел **Credentials** и создайте подключения:
   * **Postgres account** (укажите хост `bot_postgres`, порт `5432` и креды из `.env`).
   * **Telegram API** (укажите токен вашего бота от `@BotFather`).
   * Учетные данные для используемой LLM (OpenAI / OpenRouter / Anthropic).
3. Импортируйте оба файла из папки `workflows/` (меню справа сверху -> **Import from File**).
4. **Важно (привязка субагента):** Откройте главный воркфлоу (`core_agent`), найдите ноду **Execute Workflow** (в ветке обработки `callback_query` и в конце ветки переноса) и заново выберите импортированный воркфлоу `evening_wizard` из выпадающего списка.
5. В нодах **HTTP Request** внутри `evening_wizard` вставьте свой токен Telegram-бота в URL запросов.
6. Переведите переключатели обоих воркфлоу в правом верхнем углу в положение **Active**.

## Схема базы данных

* `user_session` — хранит `user_id`, текущий режим конечного автомата (`1` — обычный диалог, `2` — ожидание даты переноса задачи) и `pending_task_id`.
* `schedule` — разовые события, задачи и точечные замены регулярных пар (с маркером `[skip_regular_id: X]` в описании).
* `regular_schedule` — циклическое расписание с привязкой к дню недели (`day_of_week` от 1 до 7).
* `goals` — цели пользователя на год, месяц или неделю.
* `ai_chat_history` — история сообщений для контекстного окна препроцессора.
